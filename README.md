### 🚀 About Us:

Devoura studio is a creative and technical digital studio specializing in modern web development and bold, impactful branding. we bring ideas to life through expertly crafted websites using Wordpress, HTML, CSS and JavaScript ensuring functionality meets aesthetics. whether you're launching a startup or refining your online presence, we blend design and development into one seamless experience, built to perform, made to inspire.

🌱 &nbsp;We're currently learning: **React (a powerful JavaScript library for building fast, dynamic, and reusable user interfaces) - Figma (a collaborative, browser-based design and prototyping tool)**  
🔭 &nbsp;We're currently working on: **Devoura studio's portfolio website (Wordpress) and a tiny full-stack web development project called Yelpcamp (a full-stack campground discovery and review app — think yelp, but for campsites)**  
👯 &nbsp;We're looking to collaborate on: **open-source full-stack web development projects or any related projects that require problem solving**  
🤔 &nbsp;We're looking for help with: **all of our technical knowledge around web development or even web designing that would solve a problem.**  
💬 &nbsp;Ask me about: **anything that you are interested in around making, developing and designing websites and web apps or you are curious to how do you should work with technical tools to make your own website. under any circumstances, we're in.**  
⚡ &nbsp;Fun fact: "**Hours And Hours Of Debugging — Finally Found A Missing Comma**"
